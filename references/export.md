# 按需导出 PDF

用户要求 PDF 时才使用；普通对话分析不生成文件或安装依赖。保留当前请求的标题、格式、语言、篇幅及保存位置；没有指定位置时采用宿主的交付目录。

## 转换

1. 先完成可核对的 Markdown 内容；报告组织遵循本轮请求与宿主规则。便携导出稿可用首个一级标题作为封面标题。
2. 使用实际可用的 Python 环境，检查 `markdown` 与 `weasyprint` 是否可导入。依赖缺失时先检查宿主已有运行环境；没有可用环境时保留源文件并报告未完成的导出，不为研究正文修改系统 Python。macOS 上若包已安装但报找不到 `libgobject` 等排版库，先核对本机是否已有库；确有库时可只给当前转换进程指定库目录，不修改全局环境或重复安装。
3. 调用本 Skill 的 `scripts/md_to_pdf.py`。示例中的 `<skill-dir>` 是实际指南目录，输入输出路径使用本轮已确定的路径：

```sh
python <skill-dir>/scripts/md_to_pdf.py input.md output.pdf --title "研究对象名称"
```

只有用户指定本次产出作者时才添加 `--author "作者名称"`。未指定时省略作者行；数字生命卡兹克是方法来源，不自动成为本次产出作者。方法出处在正文中署名和链接。

## 原有排版能力

转换程序保留 A4 页面、封面、中文字体回退、页眉页脚、标题层级、表格斑马纹、引用块及代码样式。首个一级标题用于封面，不在正文重复。含研究时间或领域的元信息可显示在封面；不为排版编造作者、日期或研究数据。

程序同时生成便于检查的 HTML 与 PDF。完成后核对标题、中文、表格、来源链接、分页及作者行。命令成功只能证明转换结束，实际查看文件后才能确认排版；依赖失败时不能把已生成的 HTML 称为 PDF 完成。
